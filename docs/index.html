#이름길드Lv경험치완료 과제

상태 정의 (2026-07-25 갱신) — 미시작: 과제가 멤버 목록에 미노출(아직 착수 전) / 미진행: 등록 후 대기중(작업 중) / 평가중: 진행중 — 실제로 평가 받는 중 / 완료: 평가완료 (FAIL 포함, 별도 표기)

분모: 각 상태 비율은 스코프 총원 기준입니다 (전체 = 수집 멤버 수, 길드 칩 = 해당 길드 인원). 미노출 멤버는 미시작으로 카운트됩니다. 멤버는 소속 첫 길드로만 귀속됩니다 (이중 집계 방지).

랭커 보드: 레벨 내림차순 → 경험치 내림차순 정렬. 경험치는 사이트 스터디 유저 검색 값을 멤버 ID로 매칭한 것이며, 매칭 실패 멤버는 "-" 표기됩니다.

과제 축: 과정별 마스터 목록 기준이며 순서는 커리큘럼 순(uqstnSqnt). 아직 아묵도 착수하지 않은 과제는 미시작 100% 카드로 표시됩니다. 마스터 조회 실패 시 배정된 과제만 표시됩니다. 학습시간 표기는 분 단위 추정입니다.
